# 地図ラボ（chizu-lab）

中学受験の地理を、地図と統計でいっしょに覚えるWebアプリ。中学受験にでる範囲の地理情報を視覚的にまとめ、数値は農水省の作物統計、経産省・総務省の経済構造実態調査、国勢調査・人口推計などの一次統計（e-Stat）を根拠にしている。

- 都道府県・県庁所在地・政令指定都市
- 山脈・山・川・湖・平野・盆地・台地・半島・岬・島・海流
- 世界遺産（イラストアイコン付き、2026年7月時点の27件）
- 人口・人口比率・人口密度・面積（2025年国勢調査）
- 農産物・畜産・水産・工業の都道府県ランキング1〜10位（品目ごとにデータ年を表示）
- 白地図テスト（名前を消して覚えたか確かめる）

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力（Vercel はこれを配信）
```

## データの場所

| ファイル | 中身 | 更新方法 |
|---|---|---|
| `src/data/rankings.json` | 産物・工業のランキング | `scripts/update_stats.py` で自動生成（手で編集しない） |
| `src/data/prefectures.json` | 県庁所在地・人口・面積・政令市・伝統工芸品 | 手で編集（人口は国勢調査／人口推計） |
| `src/data/heritage.json` | 世界遺産 | 手で編集（毎年7月の世界遺産委員会のあと） |
| `src/data/geography.json` | 地形・海流・工業地帯 | 手で編集（ほぼ変わらない） |
| `src/data/map.json` | 都道府県の形 | `npm run build:map <japan.topojson>` |

## 統計の更新手順

1. e-Stat で新しい年の表を探し、`scripts/update_stats.py` の `S`（年・出典）と `ITEMS` の `sid`（statInfId）を差し替える
2. `python3 scripts/update_stats.py` を実行（`pip install pandas openpyxl xlrd` が必要）
3. 「⚠」が出たら、列番号（`col`）がずれていないか表を確認する
4. `npm run build` で確認してコミット

| 統計 | 公表のめやす | e-Stat |
|---|---|---|
| 作物統計（米・麦・大豆・茶など） | 毎年3〜8月（前年産） | 00500215 |
| 野菜生産出荷統計 | 毎年春〜夏（前々年産の確報） | 00500215 |
| 果樹生産出荷統計 | 毎年12月（前年産の確報） | 00500215 |
| 畜産統計 | 毎年7月（2月1日現在） | 00500222 |
| 漁業・養殖業生産統計 | 毎年2〜3月（前々年の確報） | 00500216 |
| 経済構造実態調査（製造業） | 毎年7月（前年実績） | 00200555 |
| 人口推計 | 毎年4月（前年10月1日現在） | 00200524 |

## 出典

- 統計：総務省統計局、農林水産省、経済産業省（e-Stat）
- 地図：[dataofjapan/land](https://github.com/dataofjapan/land)（国土数値情報をもとに作成）
- イラスト：すべてオリジナル
